# 🖱️ Mouse_controller

A real-time motion-controlled cursor platform that transforms a smartphone into a wireless gyroscopic mouse using motion sensors, WebSockets, Python, Android integration, and a modern frontend interface.

---

# 📌 Overview

Mouse_controller is a full-stack motion intelligence project that allows users to control a desktop cursor using smartphone gyroscope movement in real time.

The system uses:
- Smartphone motion sensors
- Real-time WebSocket communication
- QR-based device connection
- Python backend services
- Android integration
- Interactive frontend website
- Live telemetry visualization

The project was built to explore real-time motion tracking, wireless communication, and modern interactive system design.

---

# ✨ Features

- 🎯 Real-time gyroscope-based cursor movement
- 📡 Low-latency WebSocket communication
- 📱 QR-based instant device connection
- 🖥️ Interactive frontend dashboard
- 📊 Live telemetry monitoring
- 🔒 HTTPS and WSS support
- ⚡ Cross-platform architecture
- 🤖 Android application integration
- 🌐 Responsive modern UI
- 🎨 Futuristic interface animations
